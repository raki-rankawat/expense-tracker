# Expense Tracker

A deliberately small MERN app used to learn the full development-to-deployment
lifecycle: Docker, Compose, CI/CD, a container registry and deployment to Render.

## Getting Started

Not runnable yet — the containers arrive in features 01-03, and this section is
filled in as they land.

This project is developed in containers. `docker compose` is the way the app is
run, and tests, lint, format and build run with `docker compose exec`. Running
`npm run dev` on the host is not a supported path.
